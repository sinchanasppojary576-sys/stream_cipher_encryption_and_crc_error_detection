# Secure Communication System using Stream Cipher Encryption and CRC Error Detection

## Project Overview
Designed and implemented a Verilog-based secure communication system using the Grain-128A stream cipher for encryption and CRC (Cyclic Redundancy Check) for error detection.

## Key Features
- Grain-128A Stream Cipher Encryption
- CRC Generation and Verification
- Secure Data Transmission
- Error Detection at Receiver
- Verilog HDL Implementation

## Design Flow
1. Encrypt plaintext using Grain-128A.
2. Generate CRC bits for integrity checking.
3. Transmit encrypted data.
4. Verify CRC at the receiver.
5. Decrypt the ciphertext to recover the original plaintext.

## Tools Used
- Verilog HDL
- Xilinx Vivado
- FPGA Design Flow

## Results
- Successful encryption and decryption of data.
- Reliable CRC-based error detection.
- Maximum Operating Frequency: 1.28 GHz.
